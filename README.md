# Java OOPs Learning Repository

This repository is a beginner-friendly collection of notes and explanations for learning Java Object-Oriented Programming (OOPs). It is designed to help students and aspiring Java developers understand core OOP concepts step by step using simple explanations, examples, and a clear learning order.

## What is covered?

The repository includes topics such as:

- OOPs Introduction
- Class and Object
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interface
- Abstract Class
- Constructor
- `this` keyword
- `super` keyword
- Method Overloading
- Method Overriding
- Access Modifiers
- `static` keyword
- `final` keyword
- Association
- Aggregation
- Composition
- Exception Handling
- Error concepts

## Recommended learning order

Start from the beginning and follow the sequence below:

1. Introduction
2. Class & Object
3. Encapsulation
4. Inheritance
5. Polymorphism
6. Abstraction
7. Interface
8. Abstract Class
9. Constructor
10. `this` keyword
11. `super` keyword
12. Method Overloading
13. Method Overriding
14. Access Modifiers
15. `static` keyword
16. `final` keyword
17. Association
18. Aggregation
19. Composition
20. Exception Handling / Error concepts

## How to use this repository

- Open the `docs/` folder in your editor or GitHub repository view.
- Start with `Introduction.md` and continue in order.
- Read each topic carefully and practice the examples in Java.
- Try writing small Java programs to reinforce each concept.

## Purpose

This project is intended to serve as a study guide and quick reference for understanding OOP principles in Java. It is especially useful for:

- Beginners learning Java
- Students preparing for interviews
- Anyone revising OOP concepts
- Developers wanting a simple conceptual reference

## Notes

This repository contains documentation and conceptual learning material rather than a full application or project build. It is best used as a learning resource alongside hands-on Java coding practice.
