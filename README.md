# Java OOPs Learning Repository

A beginner-friendly Java OOP learning repository covering core object-oriented programming concepts, principles, and real-world examples with clear explanations.

This repository is designed for students, beginners, and anyone who wants to learn Java OOP concepts step by step.

## Why this repository?

Java OOP is the foundation of modern software design. This repo helps you learn:

- Class and object basics
- Encapsulation and data hiding
- Inheritance and reusability
- Polymorphism and method overriding
- Abstraction and interfaces
- Constructors, keywords, and modifiers
- Relationships between classes
- Exception handling and error concepts

## Recommended learning path

1. Start with [docs/Introduction.md](docs/Introduction.md)
2. Learn classes and objects in [docs/Class&Objects.md](docs/Class&Objects.md)
3. Understand encapsulation in [docs/Encapsulation.md](docs/Encapsulation.md)
4. Study inheritance in [docs/Inheritance.md](docs/Inheritance.md)
5. Explore polymorphism in [docs/Polymorphism.md](docs/Polymorphism.md)
6. Learn abstraction and interfaces in [docs/Abstraction.md](docs/Abstraction.md) and [docs/Interface.md](docs/Interface.md)
7. Practice constructors and keywords in [docs/Constructor.md](docs/Constructor.md), [docs/this-Keyword.md](docs/this-Keyword.md), and [docs/super-Keyword.md](docs/super-Keyword.md)
8. Move into method overloading, overriding, and access control
9. Study associations, aggregation, and composition
10. Finish with exception handling and error concepts

## How to use this repository

- Open the Markdown files in the `docs` folder.
- Read the topics in sequence.
- Practice the code examples in Java.
- Write small Java programs to understand each concept deeply.

This repository is intended for learning and reference, not for production application code. It focuses on understanding Java OOP principles with simple examples and explanations.
